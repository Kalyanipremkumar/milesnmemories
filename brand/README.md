# Miles & Memories — logo files

Generated by `build/logo.py` (run `python3 build/logo.py`). Text is converted to outlines, so the SVGs need no fonts.
Typeface: Playfair Display (SIL Open Font License, see `build/fonts/OFL-PlayfairDisplay.txt`).
Colours: navy #182B54 · gold #C38A24 · terracotta #A43B2D · ivory #F8F5EE.

| File | What it is | Where it is used |
|---|---|---|
| `logo-primary.svg` (+ PNG 600/1200/2400 px wide, transparent) | Full lockup: wordmark, lotus, tagline with rules | Social banners, print, documents, email signatures, anywhere the logo is shown large |
| `logo-compact.svg` (+ PNG 400/800) | Wordmark with lotus, no tagline | Website header: desktop at 42 px tall (tagline set as live text below it), mobile at 28 px |
| `monogram.svg` (+ PNG 32/180/512) | M&M in a gold ring on ivory | Profile pictures, avatars, apple-touch icon (`/apple-touch-icon.png`) |
| `favicon.svg` (+ PNG 16/32/48) | Same monogram reversed out of navy, drawn larger for tiny sizes | Browser tab icon (`/favicon.svg`, `/favicon-32.png`) |

The lotus is used as a pan-Indian motif; no regional architecture appears in the marks.
